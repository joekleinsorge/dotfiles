# Distinctive UI design

## Explore

Establish the intended audience, primary action, and desired feeling. Offer varied, briefly described concepts when direction is open; refine using the user's reactions. Translate the selected concept into explicit composition, typography, palette, and interaction choices.

For optional variation, generate a seed with an available random-number tool and interpret it as creative stimulus. Keep it out of the interface; never let it override the brief.

## Refine

Render the design and inspect screenshots. When independent agents are available and delegation is authorized, give a fresh critic screenshots and the brief without implementation history. Request concrete gaps against the intended aesthetic and professional reference images, considering composition and fine detail. Treat references as quality benchmarks, not templates to copy.

Fix the highest-impact gaps, then recheck. Start with at most two critique rounds; continue only when useful progress warrants it. Scores are diagnostic, not proof of quality.

Use generated imagery when it strengthens the concept. Consider video loops or keyframe transitions only when motion serves the experience. Inspect media in context.

## Finish

Remove redundant labels, decoration, and containers. Preserve purposeful details and familiar controls. Judge the result by clarity and usefulness as well as visual character.

## Implementation safeguards

These are practical additions to the source-inspired workflow:

- Follow the project's existing component system and preserve working behavior.
- Check narrow and wide viewports, keyboard navigation, visible focus, text contrast, and relevant loading, empty, and error states.
- Respect reduced-motion preferences and supply static media fallbacks. Check asset weight and layout stability.
- Use available authorized tools; do not install integrations, spend additional money, or request credentials merely to satisfy an aesthetic direction.
- If rendering or independent critique is unavailable, state that limitation instead of claiming visual validation.
- Deliver the artifact with a brief account of the chosen direction, verification performed, and unresolved limitations.
